# 📘 Hydrology AI Agent Handbook

## Purpose
This system monitors river data and generates hydrology reports.

## Workflow
1. Data ingestion
2. Discharge calculation
3. Flow analysis
4. Report generation

## Folders
- Inbox → new data arrives
- Needs_Action → processing queue
- Done → final outputs

## Agent Brain
Uses the Qwen CLI to decide which processing step runs next.
